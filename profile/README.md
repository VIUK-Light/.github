VIUK-Lightは、質問カードやAIアプリなど、使う人の時間と判断に触れるものを公開開発しています。便利さより先に、安全性・透明性・プライバシー・利用者の選択を置きます。

## Projects

| Project | なにをつくるか |
| --- | --- |
| [Omoi](https://github.com/VIUK-Light/Omoi) | 社会・倫理・価値観・人生について話す質問カード。[開く](https://omoi.viuk-light.org) |
| [Take-for](https://github.com/VIUK-Light/Take-for) | Couples / Family / Friends向けの会話シリーズ。[開く](https://omoi-for.viuk-light.org) |
| [Kizuna](https://github.com/VIUK-Light/Kizuna) | AIキャラクターとの関係と物語を、自分のペースで育てる iOS / macOS アプリ |

## How we work

不安で引き留めない。AIだけを頼らせない。できないことをやったように見せない。問題と外部通信を隠さない。

判断基準の本文は [Principles](https://viuk-light.org/principles.html) に置いています。

## Contribute

バグ報告、文章、翻訳、テスト、Pull Requestを歓迎します。参加前に各リポジトリのREADMEとライセンスを見てください。IssueにはAPIキー、会話履歴、第三者の個人情報を載せないでください。
